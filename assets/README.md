# Kitch Asset Library

This folder contains the official creative production assets for the Kitch universe.

This folder is NOT part of the application source code.

It is used for:

- Master visual assets
- Approved restaurant images
- Android character assets
- Video production files
- Mockups
- AI prompts
- References
- Exported assets for web, social and presentations

Rules:

1. Do not store production app code here.
2. Do not import directly from this folder inside Next.js.
3. Only optimized exports should be copied into /public when needed.
4. Master files remain here.
5. Every approved asset must include notes and prompt history.
6. Never overwrite approved assets without creating a new version.
