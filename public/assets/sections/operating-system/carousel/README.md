# Kitch Flow Mockup Carousel

Add the carousel mockups in this folder:

1. `01_customer_qr_menu.webp` — Cliente escanea QR / menú digital
2. `02_live_order_table.webp` — Orden viva de mesa con rondas
3. `03_waiter_approval.webp` — Panel mesero aprobando pedido
4. `04_kitchen_kds.webp` — KDS cocina con estados por ítem
5. `05_manager_panel.webp` — Manager panel con operación en tiempo real
6. `06_loyalty_followup.webp` — Loyalty / puntos / recompra

## Recommended format

- WebP
- 16:10 or 4:3 for dashboard mockups
- 4:5 if it is a mobile mockup
- Minimum width: 1400px desktop
- Keep important UI centered
