# Hero mockup stack

Product UI mockups layered in the homepage hero (desktop).

## Expected files

| File | Role |
|------|------|
| `customer-mobile.png` | Guest / mobile ordering screen (foreground) |
| `waiter-tablet.png` | Waiter tablet UI |
| `manager-dashboard.png` | Manager dashboard (background layer) |

## Paths served

- `/kitch-universe/mockups/customer-mobile.png`
- `/kitch-universe/mockups/waiter-tablet.png`
- `/kitch-universe/mockups/manager-dashboard.png`

Use transparent or device-framed PNGs. Keep file sizes reasonable for LCP (compress with WebP/PNG optimization).

Missing files show dark dashed placeholders — the page still builds and loads.
