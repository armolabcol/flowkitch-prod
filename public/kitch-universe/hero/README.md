# Hero background media

Assets for the cinematic homepage hero (`HomeHero`).

## Expected files

| File | Purpose |
|------|---------|
| `restaurant-hero.mp4` | Looping background video (muted, no critical info on screen) |
| `restaurant-hero-poster.jpg` | Poster / fallback when video is unavailable or on mobile |

## Paths served

- `/kitch-universe/hero/restaurant-hero.mp4`
- `/kitch-universe/hero/restaurant-hero-poster.jpg`

## Export guidelines

- **Format:** MP4 H.264, no audio
- **Resolution:** 1920×1080 or 1600×900
- **Duration:** 8–15 s, seamless loop
- **Weight:** ideally under 5 MB
- **Mood:** premium restaurant service, warm lighting, operational flow — not generic stock SaaS

If files are missing, the hero renders dark placeholders and does not break the build.
