# Android hero layer

Future Android device / mascot layer for the homepage hero composition.

## Expected file

| File | Purpose |
|------|---------|
| `android-hero.png` | Android character or device illustration on the right side of the hero |

## Path served

- `/kitch-universe/android/android-hero.png`

Use a transparent PNG with soft shadow-friendly edges. Recommended height: ~900–1200 px.

If the file is missing, an elegant dashed placeholder is shown in the hero stack.
